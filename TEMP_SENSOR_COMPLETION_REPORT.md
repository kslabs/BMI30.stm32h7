  - Разрешение: 12-бит
  - Время выборки: 387.5 циклов (для стабильности)
  - Режим: Одиночная конверсия по программному запросу


#### Core/Src/temp_sensor.c
- **Загрузка калибровочных констант** из FLASH (TS_CAL1 @ 0x08FFF814, TS_CAL2 @ 0x08FFF818)
- **Одиночная конверсия ADC3** (~500 микросекунд)
- **Линейная интерполяция** для преобразования ADC → °C
- **Защита диапазона**: -40°C до +85°C

### ✅ 3. USB протокол (Vendor Interface #2)

Добавлена команда **GET_TEMP (0x31)** в `Core/Src/usb_cdc_proto.c`:

```
Запрос:  [0x31]
Ответ:   [0x80, 0x31, temp_lo, temp_hi]
```

Где `[temp_lo, temp_hi]` — температура как signed int16_t в little-endian.

### ✅ 4. Интеграция в основной цикл

- **Инициализация**: `MX_ADC3_Init()` вызывается в main()
- **Загрузка константы**: `temp_sensor_init()` вызывается в main()
- **Минимальный приоритет**: Не нарушает основной стриминг данных

## 🔧 Использование

### На микропроцессоре:

```c
#include "temp_sensor.h"

// В main:
temp_sensor_init();

// Где-нибудь в коде:
int16_t temp_c = temp_sensor_read_celsius();
if (temp_c > 60) {
    printf("[WARN] Кристалл горячий: %d°C\r\n", temp_c);
}
```

### С хоста (Python):

```python
import usb.core

dev = usb.core.find(idVendor=0xCAFE, idProduct=0x4001)
dev.write(0x03, bytes([0x31]))  # GET_TEMP
response = dev.read(0x83, 4)

# Распаковать температуру (little-endian signed int16_t)
temp = int.from_bytes(response[2:4], 'little', signed=True)
print(f"Температура: {temp}°C")
```

## ⚠️ Известные ограничения

1. **Блокирующая операция**: `temp_sensor_read_celsius()` занимает ~500 мкс
   - ✅ Решение: Использовать в фоновых задачах или периодически

2. **Точность датчика**: ±5°C (типово)
   - ✅ Решение: Использовать внешний датчик для критичных приложений

3. **Диапазон**: Работает в -40°C до +85°C; за пределами — результаты неточны
   - ✅ Решение: Уже предусмотрена защита (clamping) в коде

4. **Минимальный приоритет**: Код не имеет защиты от вытеснения
   - ✅ Решение: Вызывать вне высокоприоритетных ISR
