# Основание ниже NOISE: установка на S07 и M02, 2026-11-05

Исправление из парных Core/engine **2026-11-04-185916** установлено на обе
разрешённые платы. Пользователь предварительно подтвердил отсутствие метки
возле обеих антенн S07 и M02. Выполнен перезапуск Core; полная перезагрузка
ОС и физическая проверка дальности этим этапом не выполнялись.

Включённый фильтр принимает с каждой стороны пика ноль либо локальный минимум
**строго ниже NOISE**. Минимумы на уровне NOISE и выше пропускаются. Живой
путь использует текущий накопленный шум своего канала `max(mean, P95)`, без
множителя порога. Сравнение ширины с лимитом остаётся включительным.

Обе платы работают в режиме 6, AVG_ROI200, 200 Гц. Сохранён полный конфиг
каждой платы, включая параметры усреднения, порогов, DC, звука и индикации.
Полный конфиг побайтно совпал до и после установки:

- S07: `a822511658b80ec0165c291f3c10c265e5547191e14898924c85024ff518559a`.
- M02: `9e7e6419783ce224084c8926b822498c48ff600a9460837cf160c1d6b1b142ee`.

Проверены CM5, STM USB serial и eMMC PARTUUID. SHA трёх установленных
исходников совпали с пакетом, прошедшим 38 тестов; неизменность отдельного
dual-модуля также проверена. Итоговое повторное чтение кода, selection ENV,
конфига и состояния обеих плат прошло успешно. PID Core стабилен в каждом
окне наблюдения; процессы network/access при установке не перезапускались.
Оба графика возвращают 200 отсчётов и источник основания
`accumulated_reference` с конечным положительным уровнем шума своего канала.

Первая попытка S07 автоматически откатилась из-за слишком строгой проверки
кэша режима: штатный Core обновил только `bmi30_sel.json.ts`. Исходные файлы
и выбор версии были восстановлены, полный конфиг не изменился. Проверка
установщика исправлена: сохраняется выбранный `sel`, допускается только
целочисленная служебная метка `ts`; неизвестные поля и смена режима
отклоняются. Добавлено завершение собственного резервного таймера после
подтверждённого отката/установки. 11 локальных тестов этого исправления
прошли. Повторная S07 и последующая M02 установки завершились успешно;
резервные копии для отката сохранены на каждой плате.

Три события нижнего канала S07 при убранной метке остаются отдельным
наблюдением. Счётчики фиксируют принятые алгоритмом FIRE, а не подтверждение
физического звука/реле. До установки старый алгоритм также имел недавний
нижний FIRE; сравнительная частота и причина этих событий не установлены.
Уменьшение ложных срабатываний этим обновлением **не доказано**.
Сохранены [замороженные API-контексты этих трёх нижних событий](rpi_detection/recordings/2026-11-05/S07-lower-background-event-context-01/README_RU.md),
по три кадра подтверждения каждого. Это контекст для последующего разбора,
а не непрерывная запись исходного АЦП.

S07 проверялся по разности счётчиков за интервал и стабильности процесса.
Для M02 дополнительно проверялась монотонность счётчиков на каждом опросе.
Итоговые код/ENV/конфиг проверены на обеих платах отдельно. Это короткая
проверка работающего приложения; она не заменяет непрерывную запись с
проверкой каждого пакета, точный replay или физическую серию на 35 см.

Исходный неизменённый [пакет кода и 38 тестов](../FirmwareReleases/RaspberryPi/2026-11-04-185916-base-width-noise/README_RU.md)
и отдельный [пакет результатов установки](../FirmwareReleases/RaspberryPi/2026-11-05-base-width-noise-install/README_RU.md)
сохранены локально. Полный OTA-комплект, STM32 и сетевые настройки этим
исправлением не заменялись; глобальный latest не продвигался.

Следующий физический контроль — серия Casino на 35 см с однозначным стартом
каждого движения и отдельный фон без метки. Ранжирование прежнее: максимум
детекций, при равенстве — минимум ложных. Предыдущий результат 8/12 не
объявляется повторно подтверждённым для нового фильтра без такой серии.
