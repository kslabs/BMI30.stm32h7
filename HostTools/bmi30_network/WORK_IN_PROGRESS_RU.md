## Что выполнено

- Выбор координатора Master -> минимальный RS485 ID -> уникальное имя CM5.
- Обнаружение и обмен картой через подписанные UDP объявления и HTTP с AES-256-GCM
  шифрованием/аутентификацией содержимого. Ключ предварительно установлен через
  существующий доверенный SSH; секретов в исходниках нет.
- Зашифрованное распространение данных AP и успешно работающего внешнего Wi-Fi.
- Оценка маршрутов, предпочтение пригодного 5 GHz, ограничение 4 узлами пути,
  отбрасывание своего ID в пути, резервирование родителя на время подключения,
  hysteresis/dwell/cooldown, проба HTTPS через выбранный интерфейс.
- NetworkManager checkpoint для отката; собственный AP следует каналу STA.
- При здоровом канале активные RDP-сессии/клиенты AP запрещают оптимизационное
  переключение. Отсутствие интернета допускает восстановление.
- 15 unit-тестов прошли на CM5, включая шифрование и replay; Windows пропускает
  один криптографический тест из-за отсутствующего python cryptography.
- Наблюдением подтверждено, что все пять видят пять узлов, выбирают M01 и имеют
  прямой интернет на 5180 MHz. Не утверждать оптимальность измеренной пропускной
  способности: измеряются сигнал и HTTPS-проверки, а не throughput.
