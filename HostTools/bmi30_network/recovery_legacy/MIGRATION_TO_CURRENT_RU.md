# Итоговая версия для четырёх клиентских плат

Уточнение пользователя 27.10.2026: конечная цель — новая рабочая версия ПО
на всех четырёх приборах. Восстановительная прошивка на старой основе допустима
как промежуточный шаг, но не считается завершённым обновлением всего комплекта.

M01 BMI30-05AB38E6A, S11 BMI30-D5507EDFC, S13 BMI30-7AA5CED27,
S12 BMI30-27448D72B. Последняя пока недоступна по Wi-Fi, видна по RS485.
Прямого SSH к клиентским платам агент не получил. Установка выполняется
пользователем из штатного серверного меню; доступ к порталу — через BMI30 Hub.
Не приравнивать браузерный портал/HTTP-туннель к прямому SSH-доступу.

Рабочая основа — bundle 2026-10-23-1514 / RPi 2026-10-23-151427,
полная сеть 0.2.4. Этот комплект был проверен на M10/S09, но его перенос
с восстановлением старой клиентской 0.1.13 ещё не проверен на стенде.
Рендер совместимого служебного обработчика 0.2.4-recovery4 подготовлен.
Это дерево для ревью, не готовый опубликованный установщик.

Пакет 2026-10-27-133000, уже установленный пользователем, сохраняет Core/Engine/GUI
из клиентского 2026-10-05-1930 и меняет служебный обмен. Кандидат 144513 также
основан на старом комплекте и не является итоговым обновлением всех компонентов.

Для полного нового комплекта недостаточно заменить номер версии или один
service.py: переносится весь набор зависимостей сети 0.2.4 и необходимых
системных служб. Требуются сохранение пользовательских настроек/калибровок,
ключа группы, паролей и индивидуальных AP-подсетей, полный независимый откат
системных файлов и повторная прошивка при неуспешном восстановлении.

Сначала доступные три платы получают совместимый новый комплект и пробуют
восстановить связь со старой S12. После восстановления S12 получает тот же
новый комплект. Физическая S12 не считается обновлённой по наличию её STM32
в списке RS485; нужна проверка RPi/сети/сервера на самом устройстве.

Текущие RPi-пакеты не прошивают STM32. Её обновление до рабочего 1.2.56 —
отдельная операция с проверенным способом программирования и идентичностью
чипа; наличие Internet/портала само по себе такого способа не доказывает.

Стенд выключен по сообщению пользователя. Позднее будут подключены другие
платы: перед радиотестом определить их физические идентификаторы, рабочий
носитель и версии. Публикацию финального комплекта и активацию не заявлять
выполненными до настоящих проверок и квитанции серверного publisher.
