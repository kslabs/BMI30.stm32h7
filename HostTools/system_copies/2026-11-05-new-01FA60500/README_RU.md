# Новый Raspberry BMI30-01FA60500: USB → eMMC, 2026-11-05

CM5 `366b6f101fa60500`, адрес на момент проверки `192.168.0.133`.

Перенесена USB-копия S07 с ПО Raspberry `2026-11-04-185916` на собственную eMMC нового Raspberry. Реальная загрузка с eMMC подтверждена новым boot ID, режимом загрузчика 1, устройствами root/boot и UUID. Сейчас root `/dev/mmcblk0p2` (`2da3faaa-02`), boot `/dev/mmcblk0p1` (`2da3faaa-01`); USB не смонтирован.

Сохранены собственные системные идентификаторы и SSH-ключи прежней eMMC; параметры детектора с USB перенесены без изменения значений. Сеть, Интернет, Core, портал и слушатель RDP 3389 проверены на eMMC. Хотспот `BMI30-01FA60500`, адрес `10.69.7.1/24`. Постоянная конфигурация EEPROM не менялась: для испытания использован однократный порядок `0xf41`. При следующем включении выбор носителя определяется прежним BOOT_ORDER; для обычной работы с eMMC USB следует убрать после штатного выключения.

Отсутствовавший журнал RDP создан с правами установленного пакета (`xrdp:adm`, 0640); конфигурация xrdp не менялась. Графический вход Windows пользователем ещё не проверен. STM32 к этому новому Raspberry не подключён, работа приёма и детектора на физическом сигнале здесь не проверялась.

Фильтр исправлен, запись успешно продолжена без повторного форматирования; исходная резервная копия настроек сохранила прежнюю контрольную сумму.
