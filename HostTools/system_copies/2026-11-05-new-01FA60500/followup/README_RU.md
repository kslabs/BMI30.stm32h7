# Отдельная проверка Raspberry 192.168.0.133

После уточнения адресов повторно проверен именно `BMI30-01FA60500`,
CM5 `366b6f101fa60500`. `.160` — другой прибор, M04 с подключённым STM32.

На `.133` подтверждена новая загрузка с собственной eMMC: boot ID
`0a26b69b-97cd-4360-a83f-8bc38c79a875`, режим загрузчика 1,
root `2da3faaa-02`, boot `2da3faaa-01`. Четыре исходных файла работающего
Core/engine **2026-11-04-185916** совпали с проверенными контрольными суммами.
Значения конфигурации, собственная системная идентичность, Wi-Fi/Интернет,
хотспот, портал, Core и слушатель RDP прошли повторную проверку.
USB-разделы не смонтированы; физическое отсутствие USB этим не утверждается.

Двухуровневое меню `utilities/menu.sh` уже установлено. Все 31 программный
файл утилит и шесть проверенных корневых launcher-файлов побайтно совпадают
с текущим S07; присутствуют подменю версий, дисков и сети. Дополнительная
установка утилит не выполнялась. Это проверка файлов и структуры кода;
открытое пользователем окно терминального меню непосредственно не наблюдалось.

STM32 на `.133` не обнаружен в USB, Core сообщает `connected=false`,
принимаемых кадров нет, поле версии STM32 в API портала пустое.
Номер `1.2.44` и ID `1ED3E6AF5`, приведённые пользователем, относились
к подключённому M04 на `.160`.

Заголовок Raspberry берёт номер базового пакета `2026-11-03-172055`.
Выбранная и реально работающая пара Core/engine — `2026-11-04-185916`;
это отдельные сведения о пакете и текущем приложении.
Изменений программ, настроек, носителей и загрузчика при этой повторной
проверке не было. Прошивка STM32 и физическая детекция здесь не проверялись.
