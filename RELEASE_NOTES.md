# RELEASE NOTES — Последняя рабочая версия

Дата: 2025-11-15

Коммит: 74686b4 (HEAD на ветке rollback/diag-2025-11-02)
Тег: v2025-11-15-working-gui

Краткое описание
-----------------
Зафиксирована рабочая версия прошивки и хост-инструментов, в которой:

- Восстановлен стабильный двухканальный поток ADC (каналы A и B читаются парно).
- Сделан профиль по умолчанию: 200 Hz / 1375 samples (профиль A).
- Введён общий callback ADC1, который перезапускает оба DMA и публикует пары.
- Отключён шумный селективный рестарт канала B в watchdog (оставлен только общий restart BOTH).
- Исправлены мелкие баги в формировании USB‑фреймов и увеличена устойчивость GUI-осциллографа.

Проверки и тесты
-----------------
- Собрана Debug‑сборка и ELF прошит на плату (OpenOCD), flash прошёл успешно.
- Прогнан хостовый тест стрима 30 с (Host: Stream 30s) — стабильное поведение отмечено.
- GUI (HostTools/gui_oscilloscope.py) стартует и получает кадры; в логах видны пары и статистика.

Как откатиться к этой версии
----------------------------
Чтобы вернуться к зафиксированному состоянию, выполните в корне репозитория:

```powershell
git fetch origin --tags
# По тегу
git checkout v2025-11-15-working-gui

# Или по ветке
git checkout stable/gui-200Hz-2025-11-15
```

Примечания и рекомендации
-------------------------
- Этот релиз фиксирует рабочее состояние для дальнейшей стабилизации GUI и тестирования профиля 200Hz/1375.
- Для дальнейших экспериментов рекомендую создавать от этой ветки feature‑ветки и не вносить отладочные логи в основной поток.
