# BMI30 — текущая исходная база

Разработка продолжается в `main` от STM32 **1.2.59-host-tx-lcd** и Raspberry runtime **2026-11-06-151000**.

- STM32: `Core/`, `USB_DEVICE/`, `Drivers/`, `Middlewares/`; полный SDK в `SDK/`, закреплённая сборка в `BuildSupport/STM32/`.
- Raspberry: полное дерево выпуска в `Runtime/RaspberryPi/`; активные компоненты определяет внешний `host/bmi30_split_active_version.env`.
- `HostTools/` содержит вспомогательные средства и исторические отчёты. База runtime находится в `Runtime/RaspberryPi/`.
- Сохранённые исходные пакеты последних выпусков — в `FirmwareReleases/`.

Проверка исходной базы без обращения к приборам:

```powershell
.venv/Scripts/python.exe scripts/build_stm32.py --jobs 4
.venv/Scripts/python.exe scripts/verify_raspberry_baseline.py
```

Первый запуск требует Python 3 и GNU Tools for STM32 GCC 13.3.1; путь к GCC можно передать через `--toolchain`. Проверочная сборка сверяет закреплённые хеши исходников и BIN. При модернизации спецификация сборки и ожидаемые хеши обновляются отдельным осознанным изменением.

Хранение версий: до одного календарного месяца — откат, от одного до двух — архив восстановления, старше двух — удаление сохранённой версии. Основная ветка одна. Подробности, расположение резервов и результаты очистки: [база от 12.11.2026](docs/BASELINE_2026-11-12_RU.md).
