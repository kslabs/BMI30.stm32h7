# Архив установленного комплекта Raspberry Pi

`BMI30-RPi-2026-09-29-1720.tar.gz` — неизменённый комплект, установленный на
S13, S11, S12, M01 и внутреннюю eMMC S13. Это архив приложения, не образ ОС.

- ID комплекта: **2026-09-29-1720**.
- Версия в портале: **2026-09-29-171920**.
- Время создания: **2026-09-29T15:19:20Z**.
- SHA-256: `c6a7339d1f172f456a1bf54c710eb01dc5113b9b3c2729d41bf54a098994f9f6`.
- Python на проверенных устройствах: **3.11.2**, одинаковые 140 Python-пакетов.

Внутри — core, engine, GUI, portal, USB-модули и заводская конфигурация.
Личные настройки/калибровки плат, временные SSH-ключи и учётные данные не включены.
При восстановлении использовать штатный `switch_bmi30_split_versions.sh --validate`
и `--activate` с сохранением настроек конкретного устройства.
Архив сохраняет исходные идентификаторы релиза, `manifest.env` и `SHA256SUMS`.

На Group Mode под LED indication добавлены разрешение реле, минимальное время ON,
фактическое состояние PC1 и удерживаемый Test/Stop. Таймер реле независим от звука/LED.
20 автоматических тестов и веб-проверки с чтением PC1 выполнены;
испытание с физической меткой отдельно не выполнялось.
