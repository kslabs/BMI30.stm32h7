# Эталонная прошивка STM32 1.2.44

Файл `BMI30-STM32-1.2.44-golden.bin` — сохранённый эталон прошивки для
STM32H723. Образ дважды подтверждён чтением с работающих устройств: дампы
COM18 и COM28 совпали побитно и оба содержат строку версии `1.2.44`.

- адрес записи: `0x08000000`;
- размер образа: `524288` байт (`0x80000`);
- последний занятый байт: `0x0804798B`;
- SHA-256: `334A0F0F2B4C18464C15D006802846B90D291AD77F0EB8396D9599AD4657D665`;
- исходный коммит: `fb267a4` (`Save current firmware 1.2.44 baseline`);
- тег исходников: `pre-radio-sync-fw-1.2.44-2026-08-27`.

Образ заканчивается до сектора пользовательских DC-настроек
`0x080E0000..0x080FFFFF`; запись этого файла не затрагивает данный сектор.

Пример записи через STM32CubeProgrammer CLI:

```powershell
STM32_Programmer_CLI.exe -c port=SWD freq=1000 ap=0 sn=<ST-LINK_SN> -w .\BMI30-STM32-1.2.44-golden.bin 0x08000000 -v -rst
```

После записи версию следует подтвердить повторным чтением Flash или командой
версии прошивки.
